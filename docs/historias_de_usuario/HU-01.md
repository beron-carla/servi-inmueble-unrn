# HU-01 · Registro de nuevos usuarios

================================================================================

Como visitante del sitio, quiero crear una cuenta, para acceder a las
funcionalidades autenticadas.

--------------------------------------------------------------------------------
Feature: Registro de usuarios
  Como visitante quiero crear una cuenta para acceder al sistema

  Background:
    Dado que no hay una cuenta registrada con email "juan@mail.com"

  Scenario: Registro exitoso
    When visits "/auth/registro"
    And completa el formulario con nombre "Juan Pérez", email "juan@mail.com",
        password "Secreta123" y rol "Propietario"
    And acepta los términos
    And presiona "Registrarse"
    Then ve el mensaje "Registro exitoso"
    And el usuario "juan@mail.com" existe en el sistema con estado "Activo"
    And recibe un email de bienvenida

  Scenario: Registro con email duplicado
    Given existe un usuario con email "juan@mail.com"
    When registers with email "juan@mail.com"
    Then ve el error "El email ya se encuentra registrado"
    And no se crea un nuevo usuario

  Scenario Outline: Validaciones de registro
    When completes the register form with password "<password>" and name "<nombre>"
    Then sees the error "<error>"

    Examples:
      | nombre     | password   | error                              |
      |            | Secreta123 | El nombre es obligatorio           |
      | Juan Pérez |            | La contraseña es obligatoria       |
      | Juan Pérez | corta      | Mínimo 8 caracteres                |
      | Juan Pérez | Secreta123 | El email debe tener formato válido |

--------------------------------------------------------------------------------
Criterios de aceptación:
  CA-01.1: El password se guarda hasheado (bcrypt/argon2), nunca en texto plano.
  CA-01.2: El email se valida por formato y unicidad (case-insensitive).
  CA-01.3: Password mínimo 8 caracteres, con al menos una letra y un número.
  CA-01.4: El rol por defecto es Propietario; solo un admin puede crear
           usuarios con rol Administrador.
  CA-01.5: Cuentas nuevas nacen Activas.
