# HU-07 · Alta de tipos de servicio

================================================================================

Como Administrador, quiero dar de alta tipos de servicio en el catálogo, para
que los propietarios puedan vincularlos a sus inmuebles.

--------------------------------------------------------------------------------
Feature: Alta de tipos de servicio

  Rule: Solo el rol Administrador gestiona el catálogo maestro

  Scenario: Alta de tipo de servicio exitosa
    Given que un "Administrador" está logueado
    When crea un tipo de servicio con nombre "Energía Eléctrica",
        categoría "Público", unidad "kWh" y proveedor "Edenor"
    Then el tipo de servicio aparece en el catálogo
    And los propietarios pueden verlo al vincular un servicio

  Scenario: No permite nombre duplicado
    Given existe el tipo "Agua Potable"
    When intenta crear otro tipo con nombre "Agua Potable"
    Then ve el error "Ya existe un tipo de servicio con ese nombre"

  Scenario: Acceso denegado a propietarios
    Given que "juan@mail.com" está logueado con rol "Propietario"
    When visits "/admin/tipos-servicio/nuevo"
    Then ve el error 403 "No tiene permisos para esta acción"

  Scenario Outline: Validaciones de alta
    When crea un tipo con nombre "<nombre>", unidad "<unidad>",
        categoría "<categoria>" y proveedor "<proveedor>"
    Then ve el error "<error>"

    Examples:
      | nombre | unidad | categoria | proveedor | error                              |
      |        | kWh    | Público   | Edenor    | El nombre es obligatorio           |
      | Agua   |        | Público   | AySA      | La unidad de medida es obligatoria |
      | Agua   | m³     |           | AySA      | La categoría es obligatoria        |
      | Agua   | m³     | Mixto     | AySA      | Categoría inválida                 |
      | Agua   | m³     | Público   |           | El proveedor es obligatorio        |
      | Agua   | Pesos  | Público   | AySA      | Unidad de medida inválida          |

--------------------------------------------------------------------------------
Criterios de aceptación:
  CA-07.1: Campos obligatorios: nombre, categoría, unidad de medida y
           proveedor predeterminado.
  CA-07.2: Categoría ∈ {Público, Privado}.
  CA-07.3: Unidad de medida ∈ {kWh, m³, Gigas, Moneda fija} (catálogo
           configurable).
  CA-07.4: Nombre de tipo de servicio único.
  CA-07.5: Solo el Administrador puede dar de alta tipos de servicio.
