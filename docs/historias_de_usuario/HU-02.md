# HU-02 · Inicio de sesión

================================================================================

Como usuario registrado, quiero iniciar sesión, para acceder a mi panel.

--------------------------------------------------------------------------------
Feature: Login
  Como usuario registrado quiero iniciar sesión para acceder al sistema

  Scenario: Login exitoso
    Given el usuario "juan@mail.com" existe con password "Secreta123" y estado "Activo"
    When visits "/auth/login"
    And ingresa email "juan@mail.com" y password "Secreta123"
    Then es redirigido a "/dashboard"
    And ve su nombre en la barra de navegación

  Scenario: Login con credenciales inválidas
    Given el usuario "juan@mail.com" existe con password "Secreta123"
    When ingresa email "juan@mail.com" y password "Otra12345"
    Then ve el error "Email o contraseña incorrectos"
    And permanece en "/auth/login"

  Scenario: Login de usuario bloqueado
    Given el usuario "bloqueado@mail.com" tiene estado "Bloqueado"
    When ingresa credenciales correctas
    Then ve el error "Usuario bloqueado, contacte al administrador"
    And no se crea sesión

  Scenario: Protección contra fuerza bruta
    Given el usuario "juan@mail.com" intentó login fallido 5 veces
    When intenta login nuevamente con credenciales correctas
    Then ve el error "Demasiados intentos, intente en 15 minutos"

--------------------------------------------------------------------------------
Criterios de aceptación:
  CA-02.1: La sesión usa identificador aleatorio de alta entropía regenerado
           tras el login (prevención de fixation).
  CA-02.2: La sesión expira por inactividad (30 min) y al hacer logout.
  CA-02.3: El mensaje de error es genérico (no revela si el email existe).
  CA-02.4: Todo acceso a rutas protegidas sin sesión redirige a "/auth/login".
