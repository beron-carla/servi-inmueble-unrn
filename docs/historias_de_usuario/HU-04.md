# HU-04 · Alta de usuarios (solo Administrador)

================================================================================

Como Administrador, quiero dar de alta usuarios, para autorizarles el acceso
al sistema.

--------------------------------------------------------------------------------
Feature: Alta de usuarios

  Rule: Solo el rol Administrador accede a este módulo

  Scenario: Acceso denegado a no administradores
    Given que "juan@mail.com" está logueado con rol "Propietario"
    When visits "/admin/usuarios/nuevo"
    Then ve el error 403 "No tiene permisos para esta acción"

  Scenario: Alta de usuario exitosa
    Given que un "Administrador" está logueado
    When crea un usuario con nombre "María López", email "maria@mail.com",
        rol "Propietario", estado "Activo"
    Then el usuario aparece en el listado
    And su password está hasheado
    And puede iniciar sesión con sus credenciales

  Scenario: Alta de usuario con rol Administrador
    Given que un "Administrador" está logueado
    When crea un usuario con rol "Administrador"
    Then el usuario queda con rol "Administrador"
    And el mismo puede administrar usuarios

  Scenario: No permite email duplicado
    Given existe el usuario "maria@mail.com"
    When intenta crear otro usuario con email "maria@mail.com"
    Then ve el error "El email ya se encuentra registrado"
    And no se crea un nuevo usuario

  Scenario Outline: Validaciones de alta de usuario
    When crea un usuario con nombre "<nombre>", email "<email>",
        password "<password>" y rol "<rol>"
    Then ve el error "<error>"

    Examples:
      | nombre     | email          | password   | rol         | error                            |
      |            | maria@mail.com | Secreta123 | Propietario | El nombre es obligatorio         |
      | María López|                | Secreta123 | Propietario | El email es obligatorio          |
      | María López| no-es-email    | Secreta123 | Propietario | El email debe tener formato válido |
      | María López| maria@mail.com | corta      | Propietario | Mínimo 8 caracteres de contraseña |
      | María López| maria@mail.com | Secreta123 |             | El rol es obligatorio            |
      | María López| maria@mail.com | Secreta123 | Superusuario | Rol inválido                     |

--------------------------------------------------------------------------------
Criterios de aceptación:
  CA-04.1: Campos obligatorios: nombre, email, password, rol.
  CA-04.2: Email único en el sistema (case-insensitive).
  CA-04.3: Password hasheado con bcrypt/argon2; mínimo 8 caracteres.
  CA-04.4: Rol ∈ {Administrador, Propietario}.
  CA-04.5: Solo un Administrador puede crear usuarios y asignar roles.
  CA-04.6: El usuario nuevo nace con estado "Activo".
