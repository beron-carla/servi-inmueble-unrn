# HU-13 · Vinculación de servicios a un inmueble

================================================================================

Como Propietario, quiero asociar un tipo de servicio a mi inmueble con sus
datos de contrato, para poder cargar facturas.

--------------------------------------------------------------------------------
Feature: Servicios de un Inmueble

  Background:
    Dado que "juan@mail.com" está logueado
    Y existe el inmueble "Depto Centro" de su propiedad
    Y el catálogo contiene "Energía Eléctrica" (kWh, Edenor)

  Scenario: Alta de servicio
    When vincula "Energía Eléctrica" a "Depto Centro" con CPE "017-20394856-0",
        cuenta "44556677", medidor "998877", domicilio de facturación
        "San Martín 125, 4°B" y titular "Juan Pérez"
    Then el servicio queda en estado "Activo"
    And puede dar de alta facturas para ese servicio

  Scenario: Transiciones de estado del servicio
    Given el servicio está "Activo"
    When lo cambia a "Pausado"
    Then no puede cargar facturas nuevas mientras esté "Pausado"
    When lo cambia a "En Revisión"
    Then el estado visible es "En Revisión"
    When lo vuelve a "Activo"
    Then puede cargar facturas nuevamente

  Scenario: Baja de servicio preserva el historial
    Given el servicio tiene facturas pagadas y pendientes
    When da de baja el servicio
    Then su estado pasa a "Inactivo"
    And las facturas, lecturas y pagos siguen consultables
    And no puede crear facturas nuevas

  Scenario: Un tipo de servicio solo se vincula una vez por inmueble
    Given "Depto Centro" ya tiene "Energía Eléctrica" activo
    When intenta vincularlo otra vez
    Then ve el error "El inmueble ya tiene este servicio vinculado"

  Scenario: Sin tipos de servicio disponibles
    Given el catálogo de servicios está vacío
    When ingresa al formulario de alta de servicio
    Then ve el aviso "No hay tipos de servicio disponibles.
        Contacte al administrador."

  Scenario Outline: Validaciones del alta de servicio
    When vincula un servicio con CPE "<cpe>", cuenta "<cuenta>",
        domicilio "<domicilio>" y titular "<titular>"
    Then ve el error "<error>"

    Examples:
      | cpe              | cuenta   | domicilio          | titular    | error                           |
      |                  | 44556677 | San Martín 125     | Juan Pérez | El CPE/Pagar es obligatorio     |
      | 017-20394856-0   |          | San Martín 125     | Juan Pérez | El número de cuenta es obligatorio |
      | 017-20394856-0   | 44556677 |                    | Juan Pérez | El domicilio de facturación es obligatorio |
      | 017-20394856-0   | 44556677 | San Martín 125     |            | El titular es obligatorio       |

--------------------------------------------------------------------------------
Criterios de aceptación:
  CA-13.1: Estados ∈ {Activo, Pausado, En Revisión, Inactivo (baja)}.
  CA-13.2: Campos obligatorios: tipo de servicio, CPE/pagar, número de cuenta,
           domicilio de facturación y titular; medidor opcional (no todos los
           servicios lo tienen).
  CA-13.3: Solo el propietario del inmueble (o un Administrador) puede
           gestionar sus servicios.
  CA-13.4: Un mismo tipo de servicio solo puede vincularse una vez activo por
           inmueble.
  CA-13.5: La baja es lógica e irreversiblemente preserva el historial de
           lecturas, facturación y pagos.
  CA-13.6: Solo los servicios "Activo" admiten carga de facturas.
